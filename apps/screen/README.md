# Vyron Screen

Застосунок для сенсорного екрана на принтері. Основна ціль — SPI-екран TFT35 (480×320); на HDMI-екранах 800×480 і 1024×600 той самий макет пропорційно збільшується (1rem = 1/48 ширини екрана).

Логіка спільна з Vyron Web (`@vyron/shared`): клієнт Moonraker, розбір помилок Klipper, переклади й тема. Тему екран бере з бази Moonraker, тож дизайн, змінений у браузері, діє і тут. Якщо працює Vyron Core, зміни застосовуються миттєво.

## Легкість для слабкої графіки

SPI-екран малює процесор, тому тут немає 3D, розмиття, тіней і безперервних анімацій, а шрифт системний (працює без інтернету). Збірка — один файл ~170 КБ (вебінтерфейс ~970 КБ).

## Що вже є

- Верхня смуга: стан принтера і кнопка STOP (з підтвердженням).
- Друк: кільце прогресу, файл, шар, залишок часу, температури, пауза / продовження / скасування (з підтвердженням).
- Очікування: «Готовий до друку», температури, кнопки розділів (поки «скоро»).
- Помилка Klipper: ті самі зрозумілі тексти, що у вебінтерфейсі, і кнопка перезапуску.

## Розробка

```bash
npm run dev:screen        # http://localhost:5200 — з принтером через проксі (PRINTER_URL у apps/screen/.env.local)
# http://localhost:5200/?demo&state=printing|paused|idle|shutdown — демо без принтера
npm run build:screen      # apps/screen/dist/index.html
```

Після push у `main` CI кладе збірку в корінь репозиторію як `screen.html`. На принтері вона відкривається за адресою `http://<принтер>/screen.html`.
