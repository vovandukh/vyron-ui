Шість інструментівОчікування конфігурації Klipper
Як показати температуру плат EBB36 
[temperature_sensor ebb_t0]
sensor_type: temperature_mcu
sensor_mcu: ebb0   # назва [mcu …] цієї плати
# те саме для ebb_t1 … ebb_t5

Назва датчика має містити ebb, can, board, head або tool і закінчуватись номером голови 0–5 (наприклад, ebb_t3).

Вибір головки надсилає T0–T5
Назви екструдерів визначаються через printer.objects.list. Для T0–T5 мають бути налаштовані відповідні екструдери та команди вибору інструмента у Klipper.

Мережеві інтерфейси хоста
Одноразове налаштування для підключення 
[gcode_shell_command wifi_scan]
command: nmcli -t -f SSID,SIGNAL,SECURITY dev wifi list --rescan yes
timeout: 30
verbose: True

[gcode_macro WIFI_SCAN]
gcode:
  RUN_SHELL_COMMAND CMD=wifi_scan

[gcode_shell_command wifi_connect]
command: nmcli
timeout: 40
verbose: False

[gcode_macro WIFI_CONNECT]
gcode:
  RUN_SHELL_COMMAND CMD=wifi_connect PARAMS="dev wifi connect '{params.SSID}' password '{params.PASS}'"

Потрібне розширення gcode_shell_command (ставиться через KIAUH). Це приклад, його не перевірено на твоєму принтері; якщо nmcli попросить права, знадобиться налаштування sudo або polkit.
