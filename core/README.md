# Vyron Core

Служба на хості принтера, яка працює поруч із Moonraker і об'єднує пристрої екосистеми Vyron.

## Головне правило: ядро не керує принтером

- **Білий список викликів** ([safety.py](vyron_core/safety.py)). Ядро може лише читати стан, писати у власні записи бази Moonraker (`vyron*`) і розсилати події клієнтам. G-code, старт, пауза й скасування друку, аварійна зупинка, перезапуски Klipper і хоста, служби, файли, оновлення заблоковані в коді: такий виклик навіть не надсилається. Це перевіряють тести.
- **Лише локальний сокет** `printer_data/comms/moonraker.sock`: без мережі, без нових портів.
- **Без залежностей**: лише стандартна бібліотека Python, нічого не завантажується.
- **Найнижчий пріоритет**: `Nice=15`, `CPUWeight=10`, диск у режимі idle, пам'ять до 96 МБ. Служба не залежить від Klipper чи Moonraker і не впливає на їхній запуск. Якщо вона впаде, принтер цього не помітить.
- **Не змінює чужих файлів**: printer.cfg, moonraker.conf, nginx лишаються незмінними.

## Що вміє зараз

- **Жива синхронізація дизайну.** Змінюєш тему в одному браузері, і ядро повідомляє про це решту відкритих екранів, які одразу її підтягують. Ядро лише стежить за записом `vyron_ui/design` і розсилає подію `design_changed`, саму тему воно не змінює.

## Встановлення на принтер

```bash
cd ~/voron_ui && git pull          # або оновлення через Update Manager
~/voron_ui/core/install.sh --dry-run   # подивитися, що буде зроблено
~/voron_ui/core/install.sh             # встановити й запустити
```

- Журнал: `~/printer_data/logs/vyron-core.log` (або `journalctl -u vyron-core`).
- Налаштування (необов'язково): скопіюй [vyron.conf.example](vyron.conf.example) у `~/printer_data/config/vyron.conf`.
- Видалення: `~/voron_ui/core/uninstall.sh`.

## Розробка

```bash
cd core
python3 -m unittest discover -s tests -v   # потрібен Linux/macOS (Unix-сокет)
python3 -m vyron_core -c ./vyron.conf.example -l ''
```
