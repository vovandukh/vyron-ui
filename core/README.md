# Vyron Core

Служба на хості принтера (Python, systemd), яка працює поруч із Moonraker і підключається до нього як агент.

Заплановані можливості, по черзі:

1. Каркас: служба, підключення до Moonraker як агент, журнал, оновлення через Update Manager.
2. Синхронізація між пристроями: зміна дизайну чи налаштувань в одному клієнті одразу застосовується в усіх (Web, Screen).
3. Telegram: друк завершено або обірвався, Klipper зупинився.
4. Стеження за аномаліями за телеметрією, автопауза і повідомлення в Telegram з кнопками «Продовжити» / «Скасувати».
5. Камера й AI з власним ключем користувача.

Налаштування — файл `vyron.conf` поруч із `printer.cfg`.
